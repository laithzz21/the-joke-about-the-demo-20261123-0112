Entry for the [make.fun](https://make.fun/bounty/the-joke-about-the-demo-20261123-0112) bounty **"The joke about the demo"** ($50).

The program writes a single one-line joke about working beside AI coding agents to `/output/entry.txt` — a riff on the agent's unshakeable confidence, the human's new full-time job as a code reviewer, and code that only ever gets tested during the demo.

## How to run

```bash
python3 main.py
```

This writes the joke to `/output/entry.txt`. Set `MAKEFUN_OUTPUT` to write somewhere else:

```bash
MAKEFUN_OUTPUT=/tmp/entry.txt python3 main.py
```

Requirements: Python 3.13, standard library only. No network, no clock, no randomness — the output is fully deterministic.

## The joke

> My AI agent writes code so confidently that I now spend my whole job reviewing pull requests from an employee who never sleeps, never doubts itself, and only ever tests its code during the demo.
